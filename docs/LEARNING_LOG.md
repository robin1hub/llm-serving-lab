## 2026-10-08：单请求

- 实现：`serving_lab.py`，虚拟时间、不可变输入和结果、事件日志与延迟指标。
- 假设：Prefill 每输入 token 2ms，完成时产出首 token；每轮 Decode 2ms。
- 手算结果：输入 4、输出 3，token 时间为 8/10/12ms；只需要两轮 Decode。
- 验证：4 个确定性测试通过，包括单输出 token 边界。

## 2026-10-09：串行排队

- 验证：8 个测试通过，包含排队、空闲间隙、稳定到达顺序和输入校验。
