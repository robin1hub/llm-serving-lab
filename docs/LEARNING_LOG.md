## 2026-10-08：单请求

- 实现：`serving_lab.py`，虚拟时间、不可变输入和结果、事件日志与延迟指标。
- 假设：Prefill 每输入 token 2ms，完成时产出首 token；每轮 Decode 2ms。
- 手算结果：输入 4、输出 3，token 时间为 8/10/12ms；只需要两轮 Decode。
- 验证：4 个确定性测试通过，包括单输出 token 边界。

## 2026-10-09：串行排队

- 实现：`simulate_serial()`、`serial_demo.py`；先到先服务，每请求独占 GPU 到生成结束。
- 关键规则：开始时间为到达时间与 GPU 可用时间的最大值。
- 手算结果：B 在 3ms 到达、12ms 开始、16ms 首 token、18ms 完成；等待 9ms、TTFT 13ms。
- 验证：8 个测试通过，包含排队、空闲间隙、稳定到达顺序和输入校验。
- 学习进度：用户确认理解单请求和串行等待，关注下一步真实组 batch 的过程。

## 2026-10-09：Decode batching

- 实现：`batching_lab.py` 的轮次循环和状态，`batch_demo.py` 对照串行并打印成员与进度；关键逻辑增加教学注释。
- 假设：完整单请求 Prefill 优先；无容量限制；Decode batch 整轮固定 2ms；只在轮次边界选批，不做混合 P/D batch。
- 手算与实测：轮次为 Prefill A、Prefill B、Decode [A,B]、Decode [A]；A token 时间 8/14/16ms，B 为 12/14ms。
- 验证：13 个测试全部通过，涵盖轮中到达只能下一轮选取、动态退出、空闲间隙、单输出和单请求一致性。
- 学习进度：实现完成，用户尚未确认理解本步；下一步先阅读注释、手算与改参数，再比较 P/D 优先级。
